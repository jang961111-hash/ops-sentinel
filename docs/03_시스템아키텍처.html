계층 설명

판단(Decision)은 규칙엔진이 결정론적으로 수행하고, 설명(Explanation)만 LLM이 자연어로 생성한다 — "판단은 검증 가능해야 한다"는 원칙을 지키기 위한 설계. AOP 감사로그는 비즈니스 로직과 완전히 분리된 관심사(cross-cutting concern)로, 요청 성공/실패와 무관하게 별도 트랜잭션(REQUIRES_NEW)으로 항상 기록되어 사후 검증 가능성을 보장한다.
